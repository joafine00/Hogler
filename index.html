Hogler language rules:

  • +2 Cipher: Each letter shifts 2 positions in the alphabet.
  • Initials: Long names use only the first letters of each part.
  • Swap names: First and last names can be inverted.
  • Abbreviations: Long words are shortened into symbols.
  • Pronunciation: Each word is read following +2 shift and symbol conversion.
  • Special characters: Accents and symbols are normalized before +2 shift.
